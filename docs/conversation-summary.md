# 历史对话摘要

`semanticSummaryGroups` 默认是空列表。显式添加群号并重启后，仅该群按用户隔离的会话可以在上下文压力下使用模型选择历史原文证据；合并群会话、私聊、媒体、工具协议、记忆和当前请求仍使用现有确定性处理。

每个任务最多增加一次摘要请求，无重试，输入估算上限 4096 Token、输出上限 512 Token、超时上限 5 秒。摘要与普通回复共享执行、轮数和费用预算，所以开启可能增加成本和延迟。它适合保留长历史中的关键句子，并不保证比节选更便宜。估算采用两倍余量，不是供应商的精确分词结果。

模型只能返回原句索引，本地装配事实、决定、待办和不确定事项的原文引用。每条来源至少保留一句，保留首句与明确否定、更正；分类不证明事实、共识或权限。非法索引、关键限定遗漏、超限、没有压缩收益或模型失败时回到确定性节选。来源数量较多、正文超限或必要原句过长时，也可能直接使用节选。

确定性节选同样在原有长度预算内保留完整的否定、更正和撤回句，再分配开头和末尾的摘录。必要限定句超过预算时，不生成摘要，继续使用既有历史裁剪。

来源引用和内容哈希保留在现有 V1 artifact 中，不替代会话正文。所有 Provider、工具、响应和最终投递边界检查会话是否仍存在、内容是否保持及配置是否仍允许。最终会话追加通过原子条件写入，历史删除或并发修改不会被本轮保存恢复。关闭范围或来源失效会终止依赖该来源的运行。重启无法重建来源授权的任务会拒绝恢复，用户需要重新发起。

费用包含摘要请求和普通回复，以实际 reported usage、缓存命中和版本化报价累计；缺失用量或未知价格显示不可用，不能当作零。参考费用不是账户实扣。

回滚时先关闭新接纳并等待或取消在途任务，清空 `semanticSummaryGroups`，再切换已验证的代码树。旧代码能解析 V1 model artifact，但没有本版的会话来源门禁，不能直接恢复仍引用这些摘要的活动检查点。保留会话、记忆与配置备份，不通过回滚数据库抹除变更。
