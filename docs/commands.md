# 命令清单

本文覆盖 GroupMate 当前全部用户可见入口：74 条 Yunzai 规则、1 个定时任务、1 个群事件监听和 2 个宿主 handler。规则按 `apps/` 下的插件分组，每条给出触发形式、权限、作用域和默认是否可用。

约定：

- **权限**：`任意成员` 由 Yunzai 规则直接放行；`主人` 对应规则上的 `permission: 'master'` 或处理函数内的 `isMaster` 判断；`群管理员`、`群主` 是在处理函数内按真实群角色重新核验的（不走 Yunzai 的 `permission` 字段）。
- **作用域**：命令实际生效的场景。标为`仅群聊`的在私聊里会明确回复“请在群里发送此命令”或等价提示。
- **默认可用**：按 `config/config.example.json` 的默认值判断。写成`需开启 X` 或 `需配置 X` 的，默认配置下执行会收到说明而不是静默。
- 同一插件内的规则按数组顺序匹配，**先命中者生效**。下表的顺序就是实际匹配顺序。
- 正则里的 `#` 前缀都是必需的，除非明确写出可省略。

## 对话

入口由 `toggleMode` 决定，默认 `at`：群里 @ 机器人即可对话；设为 `prefix` 时改用 `#chat` 前缀。

| 命令 | 权限 | 作用域 | 默认可用 | 说明 |
| --- | --- | --- | --- | --- |
| @机器人 + 内容 | 任意成员 | 群聊+私聊 | 是 | `toggleMode='at'` 时的普通对话入口，正则为 `^[^#][\s\S]*` |
| `#chat` + 内容 | 任意成员 | 群聊+私聊 | 需设置 `toggleMode='prefix'` | 前缀模式入口，正则为 `^#(图片)?chat(?!gpt)[\s\S]+`；`#图片chat` 强制图片呈现 |
| `#chat1` + 内容 | 任意成员 | 群聊+私聊 | 是 | 显式使用当前 OpenAI-compatible 配置；`#图片chat1` 强制图片呈现 |
| `#对话列表` / `#chatgpt对话列表` | 主人 | 群聊+私聊 | 是 | 列出当前存在的会话 |
| `#结束对话` | 任意成员 | 群聊+私聊 | 是 | 还接受 `新开`/`摧毁`/`毁灭`/`完结`，可带 `api`/`API` 前缀，`#` 可省略；只结束发送者自己（或合并会话）的上下文，**不支持指定他人** |
| `#结束全部对话` | 主人 | 群聊+私聊 | 是 | 同上的动词集合，清空全部会话 |
| `#chatgpt文本模式` | 任意成员 | 群聊+私聊 | 是 | 本人回复改为纯文本 |
| `#chatgpt图片模式` | 任意成员 | 群聊+私聊 | 是 | 本人回复改为图片 |
| `#chatgpt语音模式` | 任意成员 | 群聊+私聊 | 需配置 TTS 后端 | 本人回复改为语音 |
| `#chatgpt语音换源` | 任意成员 | 群聊+私聊 | 需配置 TTS 后端 | 在已配置的 VITS / Azure / VoiceVox 之间切换本人语音来源 |
| `#chatgpt设置语音角色` | 任意成员 | 群聊+私聊 | 需配置 TTS 后端 | 还接受 `设置角色语音`、`设置角色`；设置本人在当前后端的语音角色 |
| `#OpenAI余额` | 主人 | 群聊+私聊 | 需服务方支持额度接口 | 还接受 `#openai剩余额度` 等组合；该规则无 `^` 锚定，可出现在消息中间 |
| `#加入对话` / `#chatgpt加入对话` | 任意成员 | 仅群聊 | 是 | 加入当前群的合并会话 |

## 长期记忆

## 对话偏好

`apps/preference.js` 注册一条规则 `^#对话偏好[\s\S]*$`。偏好只在回复本人的普通对话里生效，不改变人设、群规则和工具权限。默认开启（`conversationPreferencesEnabled`），主人可在锅巴关闭。详见[对话偏好说明](conversation-preferences.md)。

| 子命令 | 权限 | 作用域 | 说明 |
| --- | --- | --- | --- |
| `#对话偏好` / `#对话偏好 帮助` | 本人 | 群聊+私聊 | 列出用法 |
| `#对话偏好 查看` | 本人 | 群聊+私聊 | 查看本人当前称呼、语气和详略 |
| `#对话偏好 称呼 <称呼>` | 本人 | 群聊+私聊 | 单行文字，长度与字符集受限 |
| `#对话偏好 语气 <语气\|默认>` | 本人 | 群聊+私聊 | 取值见命令自身的用法提示 |
| `#对话偏好 详略 <简短\|默认\|详细>` | 本人 | 群聊+私聊 | 控制回复长度倾向 |
| `#对话偏好 清除 <称呼\|语气\|详略\|全部>` | 本人 | 群聊+私聊 | 清除指定项或全部 |

## 已移除模型的旧命令

`apps/provider.js` 用一条合成正则（优先级 100，先于所有其他插件）拦截旧 Provider 命令，统一回复“该模型模式已不再支持，GroupMate 当前仅支持 OpenAI-compatible API”。覆盖九类写法：

- 直接对话：`#chat3`、`#api3`、`#chatglm`、`#glm4`、`#bing`、`#claude`/`#claude2`/`#claude3`/`#claude.ai`、`#xh`、`#qwen`、`#gemini`，均可带 `#图片` 前缀
- 星火助手：`#星火助手`、`#星火搜索助手`、`#星火查找助手`
- 切换模型：`#chatgpt切换api3`、`#chatgpt切换必应`、`#chatgpt切换星火` 等
- Token 管理：`#chatgpt设置token`、`#chatgpt绑定bing token`、`#chatgpt删除必应token` 等
- 旧设定与 Key：`#chatgpt设置bing设定`、`#chatgpt设置claudekey`、`#chatgpt设置通义千问模型` 等
- 必应管理：`#chatgpt必应切换`、`#chatgpt必应开启建议回复`、`#chatgpt必应配置方法` 等
- Gemini 开关：`#chatgpt开启gemini搜索`、`#chatgpt关闭gemini代码执行`
- 旧翻译来源：`#设置翻译来源gemini`、`#修改翻译来源qwen` 等
- 旧会话命令：`#星火结束对话`、`#必应新开全部对话`、`#claude2摧毁对话` 等

## 刻意保留的限制

这些是已确认的现状，不是待修的遗漏：

- **Live2D 装饰不可用。** `live2d`、`live2dModel` 和 `live2dOption_*` 七个配置项仍在配置文件里，但当前图片链没有接入可审计的独立 Live2D renderer，渲染会固定降级为无装饰图片。锅巴里这些字段已标记“暂不可用”且不可编辑；真实配置中的原值不会被删除。
- **`#chatgpt导出聊天记录` 是说明桩。** OpenAI-compatible 会话没有可导出的旧式聊天记录结构，该命令返回明确说明而不是静默失败。
- **后处理器按目录动态加载。** `utils/postprocessors/` 下除 `BasicProcessor.js` 以外的文件没有静态引用，由 `collectProcessors` 扫描目录后动态 `import` 并实例化。`apps/` 下的 17 个插件同样只由 `index.js` 的目录扫描加载。做死代码清理前必须排除这两条动态路径。
- **工具开关只有 `disabledTools`。** 工具是否暴露给模型由当前场景、机器人实际群权限、必要配置和锅巴的“隐藏指定工具”共同决定，没有全局的工具总开关。
