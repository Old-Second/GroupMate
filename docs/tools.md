# 工具能力与失败处理

工具经过当前请求意图、参数、现场权限、执行时限和投递回执检查。模型选中工具或聊天任务结束，不代表工具已经成功；图片、语音、视频等操作以确认的投递结果为准。

| 能力 | 工具 | 必要条件 |
| --- | --- | --- |
| 网络查询 | search、searchImage、website、github、searchMusic、searchVideo | 相应公网服务可用；配置需要密钥的搜索后端时须提供对应密钥 |
| 天气、群成员 | weather、queryUserinfo | 天气需要高德 Key；群成员查询限当前群可访问成员 |
| 图片、头像 | sendPicture、sendAvatar | 当前请求明确要求图片操作；地址可下载且符合公网、类型和大小限制 |
| 绘图、处理、识别 | draw、processPicture、imageCaption | 绘图适配器或 ap-plugin 入口；处理/识别需要有效的 HTTPS 扩展服务根地址 |
| 游戏面板 | queryGenshin、queryStarRail | 游戏适配器或对应 miao-plugin 入口，以及可查询的游戏资料 |
| 其他媒体 | sendMusic、sendVideo、sendAudioMessage、sendDice、sendRPS | 明确请求；音乐/视频使用已查到的标识；语音需要配置的合成适配器 |
| 群管理与转发 | editCard、jinyan、kickOut、setTitle、handleMsg、sendMessage | 明确操作和目标、当前身份与机器人实际权限；跨会话发送还受独立配置限制 |
| 随机选择与分组 | randomChoice | 用户提供 2～50 个不同选项；无需联网或额外配置 |
| 日期、时区、单位 | dateTime、unitConvert | 纯本地计算；时间使用具体日期和 IANA 时区，单位须同维度 |
| 群投票与统计 | groupPoll | 当前群现有成员可创建、投自己的票；发起人或当前管理员可结算、取消 |
| 提醒与倒计时 | scheduledTask | 当前群、Redis 可用；支持一次提醒和有限次数的间隔提醒，可查询和取消 |

缺少绘图、游戏、天气、识别或处理依赖时，不向模型提供相应能力。无效的可选图片服务地址不会阻断其他工具。入口存在只表示具备调用条件，不保证第三方服务或账户当前可用。

图片处理与识别默认关闭：`extraUrl` 默认为空，需要自行配置已验证的 HTTPS 服务根地址。旧公共服务不再默认提供。语音工具只检查当前选中的 VITS、Azure 或 VoiceVox 后端，Azure 同时需要 Key 和区域。

语音的 `voice` 留空或使用“默认”时，沿用当前用户在所选后端的默认角色；未知角色在本地拒绝。OneBot/NapCat 接收原始音频并负责上传、编码，不走 OICQ 专用的语音上传协议。音乐分享在没有宿主音乐工厂时使用标准 OneBot 音乐消息。

群管理工具按当前群角色显示：机器人没有管理权限时隐藏；普通成员保留修改自己名片和短暂自我禁言；踢人只向群主或机器人主人提供，专属头衔还要求机器人为群主。执行前仍重新核验权限、明确目标和审批。锅巴配置的“隐藏指定工具”（`disabledTools`）可关闭任意指定工具，移除后恢复，下一次请求生效。

视频搜索接口失败时，`searchVideo` 使用当前配置的网页搜索后端检索 B 站视频，只接受正确域名和完整 BV 标识，并标记结果来源。该降级最多增加一次搜索请求，也可能计入搜索服务额度。`sendVideo` 默认分享链接；标题和简介无法读取时会明确说明，不编造元数据，也不声称已发送视频文件。

可直接在群里 @ 机器人提出请求：

明确的请求会直接使用可用工具；已提供的账号、时间和内容无需再次确认。真正缺少或有歧义的关键信息会一次问清。工具执行成功后以实际回执报告结果；权限审批仍遵循所选策略，被拒绝或结果未知的操作不会通过反复调用来绕过。

网页搜索保持 16 KiB 输出上限，中文或较长结果会压缩摘要并保留完整来源链接，返回有效 JSON 和压缩标记，避免因按字符截断丢掉整批结果。图片评价须有实际可见图片；个人资料里的头像地址不代表模型已经看到了画面。

| 例子 | 行为 |
| --- | --- |
| “找一张蓝天照片发来” | 搜图后发送图片 |
| “找两个讲 TypeScript 入门的 B 站视频” | 搜索视频并返回结果 |
| “分享这个视频 BV1xx411c7mD” | 向当前会话发送视频信息或链接 |
| “在面条、米饭、饺子里随机选一个晚饭” | 真正随机抽取，不重复抽取 |
| “把甲、乙、丙、丁、戊随机分成两组” | 打乱后均衡分组，各组人数相差最多 1 |
| “查询我的原神面板” | 使用已绑定 UID、已更新的喵喵面板；没有资料时需先绑定和更新 |
| “北京时间 2026 年 10 月 12 日晚上 8 点是纽约几点？” | 使用 IANA 时区换算，处理夏令时；歧义时间要求提供偏移 |
| “98.6 华氏度是多少摄氏度？1 MiB 是多少字节？” | 温度偏移与单位换算；MB=1000² 字节、MiB=1024² 字节 |
| “发起聚餐时间投票：周五、周六，今天晚上八点截止” | 创建当前群投票，返回编号；到期自动汇总 |
| “投票〈编号〉我选 2”“撤回我在投票〈编号〉的票” | 每人一票，可改票、撤票；多选需在创建时说明 |
| “查看当前群投票”“取消投票〈编号〉” | 查看汇总；取消仅限发起人或当前管理员 |
| “10 分钟后提醒我关火”“查看我的定时任务” | 创建持久倒计时，展示剩余时间和真实任务编号 |
| “明早七点半叫我起床”“提醒 @某人 30 秒后开会” | 支持自然提醒措辞和提醒词在时间前面的表达；时间有歧义时补问 |
| “30 秒后通知 @某人 开会”“一分钟后提醒我喝水” | 到期通过真实 QQ 艾特通知指定成员或自己，支持最多 8 人 |
| “从明早九点开始每隔一小时提醒喝水，共三次” | 有限次数的间隔定时任务 |
| “取消定时任务〈编号〉” | 取消未发送任务或后续次数；已进入发送的本次无法撤回 |

随机工具只返回选择或分组结果，不修改群资料或通知其他成员。重复标签需要先区分；抽取数不能超过选项数，分组数为 2～选项数。

投票、提醒、倒计时共用一个持久定时任务机制。时间不明确时先补全具体日期、时区，不猜测夏令时重复或不存在的当地时间。投票使用 2～10 个不同选项，最多 100 人，默认单选；不提供截止时间则最长 90 天，支持提前结算或取消。只返回票数和参与人数，不返回投票者身份；该匿名汇总不等于数据库对运维人员不可见。

定时触发无需再调用模型。提醒最多 30 次，重复间隔至少 60 秒，全部须在 90 天内；这里只支持明确文本提醒和投票结算。日期加减按实际经过秒数计算，`day` 为 24 小时。当前群每人最多 8 个活动，全群最多 24 个活动（其中最多 8 个投票）。全实例记录最多 128 条、64 KiB，终态保留 7 天后清理；容量满时明确拒绝，不挤掉其他任务。记录数和字节数均受限制，不能同时占满各项理论上限。列表分批返回，最多四项。到期通知串行发送，每五秒最多一项，忙时会延后。

重启后恢复未发送任务；重复提醒跳过积压次数，一天以前的过期提醒不补发。QQ 发送前重新核验发起人、机器人、加入时间、当前群访问策略、静默状态和工具开关。成员离群时不发送，离群后重新加入不会恢复旧任务；权限无法核实时延后。关闭相应工具会取消到期任务，静默期间延后。取消不保证撤回已经进入发送的消息。

通知对象与提醒正文分开保存，到期发送真实 QQ 艾特段。可指定 QQ 号、准确的群名片或昵称；同名时需直接艾特或提供 QQ 号。通知对象也须在创建时及发送前核验当前群成员身份，不支持全体艾特。普通群提醒不默认艾特任何人；旧任务缺少通知对象时继续按原文本提醒，需要艾特的旧任务请取消后重新创建。提醒使用标题、正文和底部任务编号分行展示，投票结果逐项显示票数。

发送前先持久化派发标记；QQ 回执未知或在派发中崩溃时标为“结果未知”，停止自动重试及后续重复，宁可少发一次也不重复骚扰。可查询状态后自行创建新任务；不承诺 QQ 支持严格的恰好一次投递。Redis 中的活动正文是独立业务数据，不写入长期记忆，正常部署须保留 Redis。

`sendPicture` 和 `sendAvatar` 每次最多发送四张，单张下载上限 8 MiB，下载与发送合计限制为 25 秒。下载确定失败的地址会被跳过；已经确认的图片不重复发送。部分成功会记录实际数量。QQ 已经开始发送但回执丢失时，结果保留为未知并停止后续发送，不自动重试。

`processPicture` 直接把处理结果发送到当前会话，无需再次调用 `sendPicture`。处理服务返回的内存图片或本地资源由宿主适配器接收，不作为公网地址交给模型重放。绘图、语音、视频、音乐、骰子和游戏面板同样保留投递未知结果。

网易云搜索兼容接口返回的 `text/plain` JSON，仍严格解析 JSON；普通错误文本不作为搜索结果。外部接口的超时、错误页、限额或失效媒体仍可能使工具失败。内容日志的网络诊断记录请求阶段、受控错误码及 HTTP 状态，不记录 URL、凭据或响应正文。
