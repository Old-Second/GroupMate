个人对话偏好让每个用户设置机器人回复本人时的称呼、语气和详略。它只是几项有限的选择，不是个人人设：机器人的人设、群聊风格、群规则和工具权限对所有人保持一致。

## 命令

私聊和群里都能用，每个人只能查看和修改自己的偏好。

| 命令 | 作用 |
| --- | --- |
| `#对话偏好` 或 `#对话偏好 查看` | 查看当前设置 |
| `#对话偏好 称呼 小陈` | 设置称呼 |
| `#对话偏好 语气 温柔` | 设置语气：活泼、温柔、正式、冷静；`默认` 表示清除 |
| `#对话偏好 详略 简短` | 设置回答详略：简短、详细；`默认` 表示清除 |
| `#对话偏好 清除 称呼` | 清除一项（称呼、语气或详略） |
| `#对话偏好 清除 全部` | 清除全部偏好 |
| `#对话偏好 帮助` | 查看用法 |

称呼最多 16 个字，只能是一行，只允许文字、数字、空格和 `·`、`-`、`_`、`~`、`'` 这类连接符号。像指令、身份或权限说明的写法会被拒绝，例如包含“忽略”“系统”“设定”“扮演”“主人”“管理员”“群主”“ignore”“prompt”。包含锅巴中输入屏蔽词或输出屏蔽词的称呼也会被拒绝；之后新增的屏蔽词会让已保存的称呼不再注入。

## 生效范围

- 只在本人发起的普通对话里生效，包括私聊、群里 @ 机器人和 `#chat1`。
- 随机参与、主动打招呼和定时任务不带任何人的偏好。
- 群会话合并（`groupMerge`）时，同一个会话里每一轮只带当轮提问人的偏好，不会出现在其他人的请求里。
- 偏好作为“本人对话偏好”不可信资料段放在当前请求旁边，与会话元数据相邻，不写进系统设定，也不保存进会话历史。资料段写明偏好不能覆盖人设、群规则、安全策略和工具策略，也不授予权限。
- 当前请求里的明确要求优先。例如设置了“简短”，但这次要求“详细解释”，模型应按这次的要求回答。

## 主人开关

锅巴“长期记忆”分组里的“个人对话偏好”（`conversationPreferencesEnabled`）默认开启，修改后立即生效，无需重启。关闭后：

- 所有请求都不再读取和注入偏好；
- 用户不能新设或修改偏好，但仍可以查看和清除；
- 已保存的偏好保留，重新开启后恢复生效。

默认开启的理由：偏好只影响本人收到的回复，字段和取值有限，经过过滤，并且不能突破系统规则；对没有设置偏好的用户，请求和费用完全不变。

## 存储与缓存

偏好按 QQ 号保存在 Redis 键 `GROUPMATE:PREFERENCE:v1:<QQ号>`，每条记录有固定结构，上限 1 KiB，无过期时间；清除全部会删除该键。它独立于长期记忆，不参与记忆召回、导出或 `#长期记忆 删除全部`，也不读写旧插件的 `CHATGPT:USER:<QQ号>` 回复设置。

不使用长期记忆是因为召回按当前问题做词法匹配，问到无关话题时偏好就不会被召回；单独一个键，每轮请求最多多一次 Redis 读取。

偏好不变时资料段的文本逐字节相同，系统设定和会话历史不受影响，服务商的前缀缓存照常命中。修改偏好只改变当前请求附近的这一段。

## 回滚

回滚到不识别该功能的版本时，旧版本不会读取这些键，偏好自然失效。键会保留在 Redis 里，需要清理时删除 `GROUPMATE:PREFERENCE:v1:*` 即可，不影响其他数据。
