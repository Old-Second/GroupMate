# DeepSeek 适配与参考费用

GroupMate 使用自有 OpenAI-compatible Chat Completions 适配器。推荐模型名为 `deepseek-flash`；官方仍接受的 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 按 Flash 能力和价格处理。真实配置不会被自动改写。Pro 不支持图像输入。

根据 2026-10-10 核验的[官方文档](https://api-docs.deepseek.com/zh-cn/)，上下文与最大输出分别为 1,048,576 和 393,216 Token。远端运行时仍保留原有消息、字节和执行预算上限，不按模型窗口扩大内存占用。文本估算采用两倍校准余量；它仍是启发式估算，费用只使用响应中的实际用量。

思考模式使用 `thinking`，`medium` 映射为 `high`。思考时忽略温度、将 `top_p` 限制为 0.95–1；非思考时忽略 `top_p`。思考模式不能强制 `tool_choice=required`。后续携带工具的请求保留工具轮及最终答复的完整 `reasoning_content`，展示用截断文本不会代替协议状态。旧历史缺失的思考不能恢复，仅以空状态兼容。普通历史压力会生成带来源、明确遗漏的节选摘要；不是额外调用模型生成语义事实。

公开的 `/models` API 提供能力元数据，`/user/balance` 仅提供账户余额；没有逐请求实扣金额、账单时间或实时单价接口。共享账户的余额差也不能精确归属某个请求。

参考费用按每次成功响应的缓存命中、未命中、输出 Token 分别乘以官方单价，使用整数计算后累计。输出用量已包含思考 Token，不再重复收费。

| 每百万 Token（元） | Flash 空闲 / 高峰 | Pro 空闲 / 高峰 |
| --- | --- | --- |
| 输入缓存命中 | 0.02 / 0.04 | 0.15 / 0.30 |
| 输入缓存未命中 | 1 / 2 | 4.5 / 9 |
| 输出 | 4 / 8 | 13.5 / 27 |

高峰为北京时间周一至周五 09:00–12:00、14:00–18:00，排除中国法定节假日；周末即使调休上班仍为空闲。2026 年日历依据[国务院通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)。跨峰谷边界的请求按较高单价显示上限；没有完整缓存明细时，输入全部按未命中计算上限。缺少用量、报价或日历依据显示“不可用”，不显示零费用。

报价为核验日的版本化目录，不是供应商账单。旧 checkpoint 的价格快照不被改写；新请求按当时目录独立累计。目录在 2026-11-09 进入待复核状态，费用停止显示而模型能力仍有效；发布新目录前须复核官方价格和节假日日历。不能用今天的价格重算未知历史消费。

独立 JSONL 日志增加 `model.resolution`、`context.planned`、`tool.network`，分别记录能力/报价状态、每轮来源选择与压缩计划、网络阶段和耗时；不写入凭据、网络地址或配置对象。诊断失败仍不影响聊天与 QQ 投递。
